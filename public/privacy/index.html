Privacy

Yakton Daily Privacy

Yakton Daily is designed to work without registration. The starter site does not include analytics, advertising scripts, or a user account system.

Local storage

Game progress, streaks, and personal records are stored in local browser storage so they can persist between visits on the same browser. They are not automatically synchronized to other devices. Clearing site data can remove them.

Server requests

The Cloudflare Worker provides a basic health endpoint and UTC date endpoint. Your hosting provider may process standard request metadata as part of operating the site.

Contact

A public contact address has not been configured in this starter project. Add a real project contact method before public launch if you want visitors to contact you.
